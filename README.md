# SPORTZONE — интерактивный макет магазина

## Запуск
Откройте `index.html` в браузере. Для публикации загрузите `index.html`, `style.css`, `app.js` и папку `assets` в один репозиторий GitHub.

## Страницы и функции
- Главная, каталог, карточка товара, избранное, корзина и профиль.
- Поиск по каталогу и переключение категорий.
- Выбор размера, изменение количества, добавление и удаление товаров.
- Сумма корзины пересчитывается автоматически.

## Изображения
Фотографии товаров и баннера вырезаны из предоставленного изображения макета Figma и сохранены локально в `assets/`.

Это демонстрационный фронтенд: оформление заказа и авторизация пока не подключены к серверу.
